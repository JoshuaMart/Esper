# Esper

An enriched graph of a codebase: its syntax tree and call graph, annotated with notes, served to
agents over MCP and explorable in a web interface.

> Named after the Esper machine in *Blade Runner*, which Deckard uses to explore a photograph, zoom in
> and bring out what nobody had seen.

The documentation lives in [`docs/`](docs/src/content/docs/).

```sh
cd docs && pnpm install && pnpm dev    # documentation on http://localhost:4321
```
