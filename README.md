# Esper

Graphe enrichi du code source : l'AST et le graphe d'appels d'un projet, annotés de notes, servis aux
agents par MCP et explorables dans une interface web.

> Le nom vient de la machine Esper de *Blade Runner*, avec laquelle Deckard explore une photo, zoome
> et en fait sortir ce qu'on n'y voyait pas.

La documentation est dans [`docs/`](docs/src/content/docs/).

```sh
cd docs && pnpm install && pnpm dev    # la documentation sur http://localhost:4321
```
